# SilverGuard 接线方案

> 引脚分配全部取自工程实测（`SilverGuard.ioc` + `Core/Inc/main.h`），不是凭记忆写的。
> 两个特殊点：**12 V 报警灯走低边 N 沟道 MOSFET**、**两只无源蜂鸣器并联并加一级缓冲驱动**。

---

## 1. STM32 引脚占用（已核实）

| 引脚 | 功能 | 接到哪里 | 备注 |
|---|---|---|---|
| PC13 | 输出（板载灯） | 板载 LED，无需外接 | **低电平点亮** |
| PA0 | 输入（**内部上拉已使能**） | 按键 → GND | 按下 = 低电平；**不需要外接电阻** |
| PA6 | TIM3_CH1 **PWM** | 蜂鸣器驱动管 | ARR 332～555 → 1.8～3.0 kHz 扫频 |
| PB0 | 输出 | 12 V 灯 MOSFET 栅极 | **高电平点亮**（与程序一致） |
| PB6 / PB7 | I2C1 SCL / SDA | OLED（SSD1306） | 3.3 V；上拉 4.7 kΩ |
| PA9 / PA10 | USART1 TX / RX | ESP8266 | **3.3 V 器件，绝不能接 5 V** |
| PA2 / PA3 | USART2 TX / RX | 传感器模块 | 115200 8N1 |
| PB10 / PB11 | USART3 TX / RX | SYN6288 | 9600；模块一般 5 V 供电 |
| PA13 / PA14 | SWD | 下载器 | 保留，别占用 |
| 5V / 3.3V / GND | 电源 | 见第 4 节 | — |

**串口一律 TX↔RX 交叉接**（MCU 的 TX 接模块的 RX，反之亦然）。

### ESP8266 模块侧接线（8 脚：3V3 / RST / EN / TX / RX / IO0 / IO2 / GND）

| 模块脚 | 接到 | 说明 |
|---|---|---|
| **3V3** | **独立稳的 3.3 V（≥500 mA）** | ⚠️ **绝不能接 5 V**（会烧）；就近加 **470 µF + 100 nF** |
| **GND** | GND | 与 STM32 **共地** |
| **TX** | **PA10**（STM32 的 USART1_RX） | 交叉接 |
| **RX** | **PA9**（STM32 的 USART1_TX） | 交叉接 |
| **EN** | **3.3 V** | **必须拉高**，否则模块不启动（最常见的"没反应"原因）；也可经 10 kΩ 上拉 |
| **RST** | 悬空即可 | 想加复位键就接一个按键到 GND；也可 10 kΩ 上拉到 3.3 V |
| **IO0** | **悬空 / 上拉到 3.3 V** | 运行时必须为高；**只有刷固件时**才拉低到 GND |
| **IO2** | **悬空** | 内部已上拉，**别拉低**（也参与启动模式） |

**供电要点**：ESP8266 发射瞬时电流可达 **~300 mA**，而 USB-TTL 适配器的 3.3 V 引脚通常只有几十 mA → 电压塌方会导致 **`wdt reset`**。务必单独给一路 3.3 V（≥500 mA）并就近加大电容。

**刷固件时**（本工程不需要）：`IO0 → GND` + USB-TTL + 烧写工具；烧完把 IO0 恢复悬空。

## 2. 12 V 报警灯：低边 N 沟道 MOSFET

```
        +12V ────────────┐
                         │
                 [ 12V 报警灯 ]
                         │
                         ├──────────── D（漏极）
                         │
  PB0 ──[ Rg 220Ω ]──────┤ G（栅极）      N 沟道 MOSFET（逻辑电平）
                         │                    │
                  Rpd 10kΩ                   S（源极）
                         │                    │
                        GND ──────────────── GND
```

**元件**
- `Rg = 220 Ω`（栅极限流、抑制振荡）
- `Rpd = 10 kΩ`（栅极 → 源极，**不能省**）
- 1 只 N 沟道 **逻辑电平** MOSFET

**为什么 Rpd 不能省**：MCU 复位/上电瞬间引脚是高阻态，没有下拉时栅极可能被感应电压顶起来 → **复位时灯乱闪**。加上它，PB0 没驱动时栅极≈0 V，灯确定是灭的。

**MOSFET 必须是"逻辑电平"的**（Vgs = 3.3 V 就要充分导通）。普通 IRF540 在 3.3 V 只微微导通，会发热甚至不亮。

| 灯的额定电流 | 推荐管子 | 说明 |
|---|---|---|
| ≤ 0.5 A | 2N7000 / AO3400 / IRLML2502 | 小功率，便宜 |
| 0.5 – 2 A | **IRLZ44N / IRL540N** | TO-220，逻辑电平，Rds(on)≈0.028 Ω@4 V |
| 2 – 10 A | IRLB8721 / IRLZ44N + 小散热片 | 大功率灯条 |

**散热校核**：`P = I² × Rds(on)`。例：1 A × 0.028 Ω ≈ **28 mW** → 完全不用散热片。

**要不要续流二极管**：纯 LED 灯**不需要**。只有**感性负载**（继电器、电磁锁、电机）才需要在负载两端反并 1N4007 / 1N5819。

**两个前提，务必确认**：
1. 灯是**两线可浮空**的（正极接 +12 V、负极接漏极）。如果灯的负极**必须接公共地**（外壳接地/共阳结构），低边就不适用 → 改用高边 P 沟道 + 小 NPN 电平转换，或直接上光耦/继电器模块。
2. **12 V 绝不能碰到任何一个 3.3 V 引脚**。共地是对的，但电源绝不可混。

## 3. 两只无源蜂鸣器并联

```
  PA6 ──[ Rb 1kΩ ]──┤ B
                    │   NPN：S8050 / 2N3904
       Rpd 10kΩ ────┤ E ── GND        （B–E 之间下拉，防复位乱响）
                    C ──┬── [ 蜂鸣器 1 ] ──┐
                        └── [ 蜂鸣器 2 ] ──┤
                                          │
                                     +5V（或 +12V，按蜂鸣器额定）
```

**为什么不能把两只直接并到 PA6**：一只无源蜂鸣器工作电流约 10–30 mA，两只并联 ≈ 20–60 mA，**超过 STM32 单脚 20 mA 的上限**；而且无源压电片是**容性负载**，直接驱动会把方波波形拉坏。所以必须加一级缓冲。

**元件**
- 三极管 **S8050 / 2N3904**（TO-92，Ic 可到 500 mA，富余）或小 N 沟道 MOSFET（2N7000 / AO3400）
- `Rb = 1 kΩ`（基极/栅极限流），`Rpd = 10 kΩ`（基极–发射极下拉）
- 可选：每只蜂鸣器串 **100–470 Ω** 阻尼（压电片建议串；音量够就不串）

**注意事项**
- **两只必须同型号同规格**，否则阻抗不同 → 一个响一个哑。
- 供电电压**按蜂鸣器额定**：5 V 型号接 5 V、12 V 型号接 12 V（都是"拉低导通"式驱动）。
- **压电式**蜂鸣器不用续流二极管；**电磁式（内部有线圈）** 的在蜂鸣器两端反并一只 1N4148 / 1N4007。
- 程序在 PA6 上做的是 **1.8↔3.0 kHz 连续扫频**（一个来回 0.9 s），两只并联后音高一致、响度叠加。

## 4. 供电与接地

```
  12V 适配器 ─┬─────────────────────────────► 12V 报警灯（经 MOSFET 拉低）
              │
              └──[ 降压模块 LM2596 / MP1584 ]──► 5V ─┬─► Blue Pill 的 5V 脚 ─► 板载 LDO ─► 3.3V
                                                    ├─► 蜂鸣器（5V 型）
                                                    └─► SYN6288（5V 供电）

  ESP8266：单独一路 3.3V（AMS1117-3.3 / MP1584 降到 3.3V）+ 470µF 电解 + 100nF
```

**要点**
- **所有 GND 必须共地**（12 V 侧、5 V 侧、3.3 V 侧、每个模块）。这是最常见的故障源。
- **ESP8266 必须单独稳 3.3 V**：它发射瞬间电流可达 ~300 mA，Blue Pill 板载 LDO 通常撑不住 → 表现是"连一会儿就掉线/重启"。加 470 µF 电解 + 100 nF 就近去耦。
- 12 V 输入端建议加**保险丝（1 A）**和**反接保护**（串一只二极管或 P-MOS）。
- 上电顺序：先只接 12 V→降压，量好 5 V / 3.3 V 正确，**再逐个插模块**。

---

## 5. 上电前检查清单

1. 万用表量 5 V 与 3.3 V 轨（先不插任何模块）。
2. 量 MOSFET 栅极对 GND：PB0 未驱动时应 ≈ 0 V（验证下拉有效）。
3. 确认 12 V **没有**引到任何信号排针上。
4. 量所有 GND 之间是否连通（共地）。
5. **ESP8266 的 VCC 对 GND 必须是 3.3 V**，绝不能是 5 V。
6. OLED 上电后应显示 `offline`（若全黑：先查 I²C 地址是 0x78 还是 0x7A、再查上拉）。
